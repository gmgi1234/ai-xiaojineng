成功画圆：AI接管FreeCAD

我用户提问

我现在安装了freeCAD了，可以帮我画一个圆吗？

AIAI 回答

用户自行安装好 FreeCAD 后，AI立即开始执行三步操作：

  1. 定位：搜索找到 FreeCADCmd.exe 位于 D:\Program Files\FreeCAD 0.21\bin\
  2. 编写脚本：用 Python 调用 FreeCAD API 画圆
  3. 执行：用命令行无头模式运行脚本，生成文件

Step 1：定位 FreeCAD 命令行工具

AI 通过 PowerShell 在系统中搜索，找到了 FreeCAD 的命令行工具：

PS> Get-ChildItem -Path "C:\","D:\" -Filter "FreeCADCmd.exe" -Recurse
D:\Program Files\FreeCAD 0.21\bin\FreeCADCmd.exe

Step 2：编写 Python 画圆脚本

AI编写了一个完整的 Python 脚本，创建圆心在原点、半径50mm的圆，并导出三种格式：

draw_circle.py
# -*- coding: utf-8 -*- # 使用 FreeCAD 的 Python API 绘制一个圆 # 圆心 (0,0,0)，半径 50mm，导出为 DXF 和 FCStd 格式 import FreeCAD import Part import Draft # 创建新文档 doc = FreeCAD.newDocument("CircleDrawing") # 圆心坐标 center = FreeCAD.Vector(0, 0, 0) # 法线方向（Z轴向上，即圆在 XY 平面） normal = FreeCAD.Vector(0, 0, 1) # 半径 50mm radius = 50.0 # 创建圆 circle = Part.makeCircle(radius, center, normal) # 将圆加入文档 circle_obj = doc.addObject("Part::Feature", "MyCircle") circle_obj.Shape = Part.Wire(circle) circle_obj.Label = "圆形" # 重新计算文档 doc.recompute() # 保存为 FreeCAD 原生格式 fcstd_path = r"d:\Downloads\CAD-chajian\circle.FCStd" doc.saveAs(fcstd_path) print("已保存 FCStd 文件: " + fcstd_path) # 导出为 DXF 格式（AutoCAD 可打开） dxf_path = r"d:\Downloads\CAD-chajian\circle.dxf" import importDXF importDXF.export([circle_obj], dxf_path) print("已保存 DXF 文件: " + dxf_path) # 导出为 SVG 格式（可直接预览） svg_path = r"d:\Downloads\CAD-chajian\circle.svg" import importSVG importSVG.export([circle_obj], svg_path) print("已保存 SVG 文件: " + svg_path)

Step 3：命令行执行，一键生成

用 FreeCADCmd.exe 无界面模式执行脚本：

PS> & "D:\Program Files\FreeCAD 0.21\bin\FreeCADCmd.exe" "draw_circle.py"
已保存 FCStd 文件: d:\Downloads\CAD-chajian\circle.FCStd
已保存 DXF 文件: d:\Downloads\CAD-chajian\circle.dxf
已保存 SVG 文件: d:\Downloads\CAD-chajian\circle.svg
画圆完成！半径=50.0mm，圆心=(0,0,0)

总结：AI + FreeCAD 能做什么？

  • 完全可控：FreeCAD 的 Python API 能控制几乎所有CAD操作，画圆只是起点
